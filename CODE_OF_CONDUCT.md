# Code de conduite

Ce projet veut rester un espace accueillant pour tout le monde, quels que soient l'expérience, l'identité ou
l'origine de chacun.

## Ce que nous attendons
- Être respectueux et bienveillant, y compris dans les désaccords.
- Accepter les critiques constructives et en donner de façon constructive.
- Se concentrer sur ce qui est le mieux pour le projet et ses utilisateurs.

## Ce qui n'est pas accepté
- Insultes, harcèlement, propos discriminatoires, attaques personnelles.
- Publication d'informations privées d'autrui sans son accord.
- Tout comportement qui serait jugé inapproprié dans un cadre professionnel.

## Application
Les personnes qui maintiennent le projet peuvent retirer ou modifier tout commentaire, commit, issue ou pull request
qui ne respecte pas ce code, et exclure temporairement ou définitivement un participant. Pour signaler un problème,
contactez-les par une issue ou par la messagerie privée de GitHub.
