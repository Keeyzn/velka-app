# Sécurité

Pour signaler une faille de sécurité, utilisez **GitHub Security Advisories** : onglet « Security » du dépôt, puis
« Report a vulnerability ». Merci de ne pas ouvrir d'issue publique pour une faille tant qu'elle n'est pas corrigée.

Seule la dernière version publiée reçoit des correctifs de sécurité.
